# Badge

One or two words of status or a short count beside an item.

- **You provide:** the text as `children` and a `tone`: `neutral` (default) for plain status, `brand` for highlights and scores, `success` and `danger` for state.
- The word carries the meaning. Color only supports it, so "Published" and "Flagged" read the same in any theme.
- Do keep badges to one line in the `label` style. Do place them in card headers or after a title.
- Don't make badges clickable. Use a small `ghost` Button for that.
