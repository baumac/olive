# Checkbox

A native checkbox with a clickable label for one on/off choice or one item in a set.

- **You provide:** a `label` that reads as a statement ("Show my name on reviews"), plus native props (`checked`, `defaultChecked`, `onChange`, `name`). Add `hint` for a short consequence.
- The box takes the `brand` color through `accent-color`.
- Do use it for settings that save with the form. Do group related checkboxes with `space-2` between them.
- Don't use a checkbox for an action that applies at once. Don't phrase labels as negatives ("Don't email me").
